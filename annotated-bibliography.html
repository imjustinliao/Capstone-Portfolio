Backend APIs and Supabase

We used Flask for the REST API and Supabase (Postgres + auth) for persistence. I relied on official docs and REST/API design sources to align request/response shapes with the iOS client and to structure endpoints for discovery, matching, and meet lifecycle. The sources in this section cover API design, Flask, Supabase, and Postgres.

We used Haversine distance for “who’s nearby” and Apple MapKit for in-app maps. I referenced geospatial and mapping docs to implement and tune the proximity logic and to handle location permissions and privacy (e.g., no persistent precise location). Sources here will cover MapKit, Core Location, Haversine, and related APIs.
