Annotated Bibliography

We grouped the resources below by theme to show how we learned the tools and methods used while building Serene. Each theme has a short annotation and APA-formatted entries sorted alphabetically.

Backend APIs and HTTP

We used Flask and REST API patterns plus HTTP methods to structure endpoints and communicate with the iOS app. These sources guided how we defined request and response shapes and chose the right verbs for each action.

Flask Documentation. (2024). Flask web development documentation. https://flask.palletsprojects.com/

Grinberg, M. (2018). Flask web development: Developing web applications with Python. O'Reilly Media.

Mozilla Developer Network. (2023). HTTP request methods. https://developer.mozilla.org/

Database and Authentication (Supabase)

These sources helped us learn how to store and manage user data using Supabase. We used them while setting up authentication, creating database tables, and connecting the backend to the database. They also helped us understand how Supabase handles security and user sessions.

Supabase. (2023). Authentication guide. https://supabase.com/docs/guides/auth

Supabase. (2024). Supabase documentation. https://supabase.com/docs

iOS Development, Design, and UI

We used Apple documentation and the Human Interface Guidelines to learn SwiftUI patterns and follow platform design guidance. We also used them to implement Liquid Glass carefully without hurting readability.

Apple. (n.d.). Apple Developer Documentation. https://developer.apple.com/documentation/

Apple. (n.d.). Human Interface Guidelines. https://developer.apple.com/design/human-interface-guidelines

Apple. (n.d.). Liquid Glass. https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass

YouTube. (n.d.). [Video]. https://youtu.be/Odtp_sCDNHg?si=vhxJDRHoRqHS6066

Location-Based Services

Because our app needs to connect users who are physically near each other, we researched how location-based systems work. These sources helped us understand how to handle geolocation data and how apps can determine when users are close enough to interact.

Google Developers. (2023). Geolocation API documentation. https://developers.google.com/maps/documentation

MDN Web Docs. (2023). Geolocation API. https://developer.mozilla.org/

Testing and Release Workflow (TestFlight)

We used TestFlight documentation to understand iOS beta distribution and how builds are shared for testing during development.

Apple. (n.d.). TestFlight. https://developer.apple.com/testflight/
